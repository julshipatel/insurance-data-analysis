# Insurance Data Analysis

## 📌 Project Overview

This project focuses on analyzing insurance data using **Microsoft Power BI** to understand business performance, customer patterns, and important insurance-related trends.

The analysis transforms raw insurance data into meaningful insights through data cleaning, analysis, and interactive visualizations.

## 🎯 Project Objectives

* Analyze insurance data and identify important patterns
* Understand customer and policy-related trends
* Analyze insurance performance using key metrics
* Identify factors affecting insurance business performance
* Generate meaningful insights to support business decision-making

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculations and measures
* **Data Visualization**
* **Data Analysis**

## 🔍 Analysis Performed

The project includes analysis of:

* Insurance policy data
* Customer-related information
* Insurance claims
* Premium and financial information
* Policy and claim trends
* Overall insurance performance

## 📊 Key Insights

The analysis helps understand:

* Overall insurance business performance
* Customer and policy patterns
* Claim-related trends
* Premium performance
* Areas of higher and lower business activity
* Important patterns that can support business decisions

This project demonstrates how data analysis and business intelligence tools can be used to convert raw insurance data into actionable insights.

The analysis can help organizations understand customer behavior, monitor insurance performance, identify claim trends, and make data-driven business decisions.
